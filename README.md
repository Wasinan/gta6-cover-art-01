Cover Studio builds GTA 6 style cover art from your own photos — three layouts, three photo slots, four colour grades, and exact-size PNG exports — entirely offline in the browser. Three canvas-drawn Vice City sample scenes ship with it, so it works out of the box with no upload.

## Run it

```sh
node main.ts
```

This assembles the static app into `out/` (or into `$MAKEFUN_OUTPUT_DIR` when set). Open `out/index.html` in a desktop browser.
