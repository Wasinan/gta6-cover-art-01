Cover Studio turns any photo and a caption into GTA 6-style cover art — three layouts, three photo slots, four colour grades — and exports a print-ready PNG to share. Everything runs offline in your browser: the sample photos are drawn in-session and bundled as data URLs, so the canvas never taints and no upload ever leaves the machine.

## Run it

```sh
node main.ts
```

Then open `out/index.html` in a desktop browser. No build step, no dependencies.
